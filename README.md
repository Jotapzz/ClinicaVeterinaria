# 🐾 Sistema de Clínica Veterinária

Sistema de gerenciamento para clínica veterinária desenvolvido em C# com .NET, focado na organização do cadastro de pacientes (pets), tutores e no fluxo de agendamento de consultas.

---

## 📌 Funcionalidades Principais

- 🐶 **Gestão de Pacientes (Pets):** Cadastro, listagem e atualização de informações do animal (nome, espécie, raça, idade e vínculo com tutor).
- 👤 **Gestão de Tutores:** Registro e organização dos dados dos proprietários.
- 📅 **Agendamento de Consultas:** Marcação de atendimento veterinário, histórico e acompanhamento de consultas.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C#
- **Plataforma:** .NET 
- **Tipo de Aplicação:** *.NET*
